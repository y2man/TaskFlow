# TaskFlow

A modern, responsive task management application built with React and TypeScript.

TaskFlow helps users organize their daily work, track progress, and manage tasks through a clean, interactive dashboard.

## Features

- Add, edit, and delete tasks
- Mark tasks as completed
- Filter tasks by status
- Search tasks by title
- Dashboard statistics for total, completed, and pending tasks
- Persistent task storage using browser localStorage
- Responsive design with glassmorphism and animated visual effects

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- Browser localStorage

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate into the project:

```bash
cd TaskFlow
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Production Build

```bash
npm run build
```
